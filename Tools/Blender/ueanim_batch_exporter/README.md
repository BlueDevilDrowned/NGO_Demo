# UEFormat Unity Exporter

Blender extension for exporting a UEFormat model and converting multiple `.ueanim` files into Unity-ready FBX files.

## Requirements

- Blender 4.2 or newer
- UEFormat add-on enabled
- A matching armature already imported from the character's `.uemodel`

## Install

1. Open Blender Preferences > Get Extensions.
2. Open the menu and choose **Install from Disk**.
3. Select `ueanim_batch_exporter-1.2.0.zip`.
4. Enable **UEFormat Unity Exporter** and **UEFormat**.

## Use

1. Import the character `.uemodel` and keep its armature in the scene.
2. Open the 3D View sidebar with `N`, then select **UEAnim Export**.
3. Choose the target armature and output folder.
4. Optionally set a model file name and click **Export Current Model FBX**. The target armature and every bound mesh are exported in Rest Position without animation.
5. Click **Select UEAnim Files and Export**.
6. In the file browser, multi-select the `.ueanim` files and confirm.

Each source file produces one FBX containing the armature and one baked animation. Meshes, NLA strips, and unrelated Actions are excluded.

Version 1.2 uses the same coordinate and scale conversion as **Unity FBX Batch Re-export 1.2** for both models and animations: `-Y` forward, `Z` up, baked space transforms, all scaling applied, and the complete bone hierarchy. Evaluated pose baking is enabled for animations by default.

## Unity import

Create the Avatar from the exported model FBX. On every animation FBX, use the same Rig type as the model, set **Avatar Definition** to **Copy From Other Avatar**, and select the Avatar generated by the model FBX.

## Notes

- The target armature must have the same bone names and hierarchy used by the animations.
- Model export includes meshes that use the target in an Armature Modifier or are parented below the target.
- `UE Import Scale` defaults to UEFormat's standard `0.01`.
- `FBX Simplify` defaults to `0` so baked keys are preserved.
- Keep `Bake Evaluated Pose` enabled when the armature uses constraints or when matching files produced by Unity FBX Batch Re-export.
- Existing FBX files are replaced only when **Overwrite Existing FBX** is enabled.
